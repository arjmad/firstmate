Decision: a ship brief carries the same arm-and-acknowledge rule a scout brief does, behind the same `fm-bootstrap.sh lavish-compatible` gate, so a board a ship opens has a listener while the ship runs; ship teardown hands a board whose task has an attested non-empty captain-call inventory with a call still open to firstmate, as scout teardown does for any attested inventory, and still retires any other board.
Why: ship workers opened boards with plain `lavish-axi <file>`, which no listener reads, and teardown adopted only scout boards, so four of the 34 queued answers were lost and most of the rest survived only because firstmate asked again at the helm.
It widens the [scout board handover](2026-10-27-scout-board-handover.md) from scouts to ships and leaves scout teardown unchanged; the scout brief text changes only in naming the procevent scripts by their absolute firstmate path, which a worker in another project needs to run them.
