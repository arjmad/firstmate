Decision: a ship brief carries the same arm-and-acknowledge rule a scout brief does, behind the same `fm-bootstrap.sh lavish-compatible` gate, so a board a ship opens has a listener while the ship runs; ship teardown hands a board whose task has an attested non-empty captain-call inventory to firstmate, as scout teardown does, and still retires any other board.
Why: ship workers opened boards with plain `lavish-axi <file>`, which no listener reads, and teardown adopted only scout boards, so four of the 34 queued answers were lost and most of the rest survived only because firstmate asked again at the helm.
It widens the [scout board handover](2026-10-27-scout-board-handover.md) from scouts to ships and leaves the scout brief text and scout teardown unchanged.
