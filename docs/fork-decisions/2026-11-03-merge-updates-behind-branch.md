Evidence: business PRs 668 and 667 were refused on 2026-11-03 with "head branch is not up to date", which sent a routine merge back to the helm and the worker.
The update is GitHub's merge-style update-branch bound to the verified head, never a rebase or force-push, and every existing merge gate runs again on the new head; a conflict or a failed update refuses, naming it so firstmate steers the worker.
No upstream proposal yet: the update path sits inside this fork's code-review, door, and landed-work gates.
