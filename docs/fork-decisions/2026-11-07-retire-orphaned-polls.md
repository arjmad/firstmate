2026-11-07: Arjun picked "fix it" in the 2026-11-07 grill after about 40 Lavish boards woke the helm with empty LISTENER_ACTIVE errors following a session restart on Heimdall, and four kept doing it because the dead session's poll wrappers survived as orphans and kept each board's single listener.
Decision: a locked session start stops the source children a dead runner generation of the same home left running, proved by the pid and start stamp the runner recorded for that child, never by a process-name pattern, and the Lavish adapter treats a LISTENER_ACTIVE poll as a silent no-op.
This settles the earlier open question of signalling a dead leader's surviving group only for a group that recorded proof covers; every unproved leaderless group stays refused.
