2026-11-27: Arjun asked to build audit item a1-61 ("Build it") at the 2026-11-27 walk of the 2026-11-26 deep audit.
Decision: a ship whose change also needs a file in its home's `data/` or `config/` changed does not edit that file; it records the exact diff in `data/<id>/home-patch.md` with `bin/fm-home-patch.sh add`, and the landing step shows that diff and applies exactly what it showed after the work lands, so the helm reviews one diff instead of re-deriving it.
Decision: only an attended `bin/fm-pr-merge.sh` applies a patch on its own, bound to the digest it printed before the forge merge; teardown applies only a digest an attended merge recorded as shown, and every other pending patch becomes the routine noticed row `noticed-home-patch-<id>`.
Why: before this, a ship's home-file half was described in prose and the helm re-derived and hand-edited it at landing, which was slow and easy to get wrong.
If this goes, the brief line and both landing hooks go with it; a patch already applied stays applied, because it is the change the helm reviewed.
