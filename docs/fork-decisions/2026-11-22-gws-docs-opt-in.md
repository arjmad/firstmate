Every server keeps the full `--permissions`, because upstream requests only the listed services in a new consent: a shorter list would let a sign-in from any default session narrow the one credential every runtime shares.
`--content` and `--docs` share one check, `fm_optin_mcp_check`, which takes each switch's file and sign-in tools.
No upstream proposal: the account layout and the service split are this fleet's.
