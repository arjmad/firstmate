Decision: a `config/live-checkouts` entry can carry `post-update=detached`, so its post-update command runs as a launchd one-shot (or in its own session) that outlives the sync, and a `capture-start=off` checkout behind origin fast-forwards under live edits origin did not touch instead of waiting for the scheduled capture.
This changes the [2026-11-12 `capture-start=off` record](2026-11-12-capture-start-off.md): its waiting line now holds only at origin, or behind it where origin changed an edited path.
Why: on 2026-11-26 four Heimdall merge activations died with the caller's process group before they reached the activation executor, and a merged Nova PR waited up to 18 hours for the nightly capture although no live edit touched its files.
